# 🎲 大富翁·欢乐城

网页版大富翁，玩法参考《大富翁 11》并加入了一些自己的设计。可以**单机对战电脑**、**同屏多人轮流玩**，也可以**联机**和朋友一起玩（空位可以用电脑补上）。

零依赖，只需要 Node.js 18 及以上版本。

> 🖥️ **Unity 电脑客户端**（开发中）在 [`unity/`](unity/README.md) 目录：用 Kenney 的 3D 素材、URP 渲染，规则和联机服务器和网页版是同一套。打开方法见 [unity/README.md](unity/README.md)。

## 快速开始

```bash
node server.js          # 或 npm start
# 浏览器打开 http://localhost:3000
```

- **单机 / 同屏**：在主页选择角色，添加电脑玩家或同屏玩家，点“开始游戏”。进度自动保存在浏览器里，下次可以“继续上一局”。（3D 版需要通过 `node server.js` 打开，直接双击 html 文件无法加载。）
- **联机**：一个人点“创建房间”，把 4 位房间号或邀请链接发给朋友，对方点“加入房间”。房主可以添加电脑、选择回合上限和起始资金。
  - 局域网内的朋友用 `http://你的IP:3000` 访问；想在公网玩，可以把它部署到任意能运行 Node 的服务器上（端口用环境变量 `PORT` 设置）。
  - 刷新页面或断线会自动重连；断线超过 30 秒会自动托管，回来后自动解除。

## 玩法

| 系统 | 内容 |
|---|---|
| 🗺️ 地图 | 3D 城市路网：外环路 + 中央大道 + 南北大街，5 个十字/丁字路口。走到岔路口可以自己选方向（电脑会算哪边划算），进监狱、被传送之后也能重新选方向。 |
| 🏙️ 地产 | 35 块城市地产、12 个片区，越靠近市中心越贵。买下空地后，再次停在自己的地上可以加盖，一次可盖多层：平房 → 洋房 → 公寓 → 大厦 → 摩天楼。同片区每多拥有一块地，过路费 +60%（连锁加成）。地主坐牢、住院或冬眠时收不到过路费。 |
| 👴 角色 | 阿土伯（买地 8 折）、孙小美（买卡 7 折）、钱夫人（收租 +25%）、金贝贝（工资 ¥3000）、忍太郎（无视路障地雷）、大老千（赌场可出千重来、点券翻倍） |
| 🃏 道具卡（19 种，4 类） | 移动：遥控骰子、停留卡、乌龟卡；整人：路障、地雷、陷害卡、冬眠卡、查税卡、抢夺卡；地产：购地卡、怪兽卡、天使卡、恶魔卡；财富：均富卡、免费卡、嫁祸卡、涨停卡、跌停卡、内幕卡。掷骰前使用，在道具店用点券购买（店里按类别分页，孙小美 7 折）。 |
| 📈 股市 | 6 支股票各对应两个片区（西部能源：西北+西南、华中制造：两湖+中原、北方重工：齐鲁+东北、东南贸易：闽赣+江淮、长江航运：巴蜀+吴越、湾区金融：岭南+京沪）。轮到自己、掷骰子前随时买卖，每手 100 股、手续费 1%；停在🏦证券交易所免手续费，还能打听到一支股票下回合的走势。每回合结束收盘，单回合涨跌不超过 10%；片区里买地、盖楼推高股价，拆楼、地震压低股价，新闻和涨停/跌停卡也会影响。最大股东（≥300 股）当董事长，这两个片区的每笔过路费公司另付 10% 给董事长。股票计入总资产，缺钱时先自动卖股票。 |
| ✨ 神仙 | 随机出现在地图上，经过就会附身：财神、福神、土地公、天使是好神；衰神、穷神、恶魔是坏神。可以用嫁祸卡转给别人。 |
| 🎪 特殊格子 | 机会、命运、新闻（全城事件）、幸运转盘、赌场（押大小）、道具店、证券交易所、点券站、税务局、警察局、监狱、医院 |
| 🏆 胜负 | 现金不够时自动按半价变卖地产，还不够就破产。最后一个没破产的人获胜；到达回合上限时总资产最高者获胜。 |

界面表现：
- 主页和联机房间的背景是一座慢慢旋转的 3D 欢乐城，前面是毛玻璃面板：先选角色（大卡片），再选玩法（单机/同屏、联机对战）。房间里房间号用大字格子显示，4 个座位卡片，空位显示“等待加入”。
- 城市建在一座小岛上，四周是会流动的海面；路网是带人行道和车道虚线的沥青马路，格子是嵌在路面上的圆角卡片（空地顶部是片区颜色的标题栏）。
- 路网围出的四个街区各有主题景观：西北古城（七层飞檐宝塔、城墙城楼、三间牌坊、荷花池石拱桥和柳树、灯笼、青瓦小院）、东北金融区（证券交易所楼顶有滚动的实时行情屏、玻璃幕墙塔楼、玻璃金字塔、喷泉、金牛）、西南海滨（泻湖里漂着帆船、木栈桥、彩色沙滩小屋、救生员瞭望台、灯塔的光束会转、椰子树）、东南游乐园（会跑的过山车、转动的摩天轮、旋转木马、马戏帐篷、乐园大门、气球）。
- 棋盘外面的郊区（参考《大富翁 11》和 Monopoly Plus“活的城市”）：环岛路带路沿、白边线、路灯和斑马线，小车和公交车来回跑；西北是带田埂的水田、稻草人、两座农家院（院墙门楼、草垛、水井、菜地、小鸡）、水车、温室大棚、茶园梯田和带石阶亭子的小山；东北是机场（跑道灯和编号、滑行道、波浪顶航站楼、登机廊桥、会转雷达的塔台、机库、风向袋、地勤车，一架飞机会滑行起飞、绕岛一圈再降落）、带草坪栅栏和车道的住宅区、三层看台的体育场；西边是渔村（晾鱼架、渔网）、渔船栈桥，海上有港口（起重机和吊钩、条纹集装箱、仓库、集卡、系缆桩）和货轮；东边是加油站、露营地（人字帐篷、房车、野餐桌、篝火）、热气球和海上风车；南边（镜头这一侧）只放矮的：沙滩（排球场、伞和躺椅、沙堡、救生椅）、儿童游乐场、欢迎花坛、停车场、水上乐园（螺旋滑梯、懒人河、凉亭）和游艇码头（suburbs.js，静态零件按材质合并成少量网格，细节多也不卡）。
- 整张地图按这四个街区分成四种风格：每块地产跟着最近的街区走，地面铺装、空地摆设、岛上的树（古城松树、海滨椰子树）和盖起来的楼都是同一种风格（buildings.js）。
- 股市：画面右上角是迷你行情，底部掷骰子按钮旁有“股市”按钮；股市面板有 6 支股票的走势、K 线、董事长、内幕消息和买卖按钮（红涨绿跌）。每回合收盘时播放涨跌播报，地图上对应片区飘出涨跌幅。
- 开局有开场动画：所有玩家的卡片依次飞入，然后镜头从城市全景俯冲到第一位玩家。
- Three.js 3D 场景：低多边形风格的城市。买下地产就会盖起房子，每个等级造型不同，并且按片区分四套风格：古城是亭子 → 四合院 → 两层小楼 → 三层楼阁 → 五层宝塔 → 七层宝塔；金融区是小木屋 → 平房 → 洋房 → 公寓 → 玻璃大厦 → 摩天楼；海滨是高脚沙滩屋 → 白色小别墅 → 圣托里尼圆顶屋 → 度假酒店 → 圆形度假塔 → 帆船酒店；游乐园是糖果小摊 → 姜饼屋 → 小塔屋 → 小城堡 → 四角城堡 → 童话高塔城堡。屋顶、遮阳篷、尖顶和小旗子都是地主的颜色，地块铺装也会染上地主颜色，正门朝向马路，升级时房子会“长”出来。
- 6 个角色都是 Q 版 3D 小人（characters.js，用几何体拼成）：阿土伯的草帽和拐杖、孙小美的双马尾、钱夫人的旗袍和折扇、金贝贝的棒球帽、忍太郎的面罩和武士刀、大老千的高礼帽和单片眼镜。站着会呼吸摆动并面向镜头，走路摆臂迈腿；脚下彩色底座是玩家颜色；坐牢、住院、冬眠时头顶冒出对应图标。
- 3D 棋子逐格跳跃前进，留下行走轨迹；镜头自动跟随当前玩家，可以拖动旋转、滚轮/双指缩放，右上角切换“全景/跟随”。
- 每个棋子头顶都有名字牌，当前玩家的棋子脚下有光圈、头顶有金色箭头；换人时有“轮到 XX”横幅，玩家列表实时显示每个人在哪一格。
- 机会/命运翻牌、新闻号外、幸运转盘旋转、赌场摇骰、神仙附身、道具使用都在棋盘中央播放动画（点击可跳过）。
- 收支金额从棋子头上飘出，现金数字滚动变化；买地盖“已购”章，盖楼、拆楼有动画。
- 掷骰子是真实物理：两颗骰子被扔进 3D 城市，会撞到路口、房子和棋子再弹开，每次碰撞按力度发出咔哒声，停稳后头顶弹出总点数。点数仍由引擎决定：先在后台用物理引擎算完整个抛掷过程，再按最后朝上的面重新排列骰子贴图，然后回放（cannon-es，MIT 许可，已打包在 vendor/）。不支持 3D 时退回到中央的 CSS 骰子动画。
- 音效全部用 Web Audio 实时合成（压缩器 + 短混响）：骰子摇晃与落桌的清脆碰撞、买地的收银机声和盖章声、盖楼的锤子声、付过路费的掉硬币声、转盘咔哒声、爆炸、胜利号角等；菜单里可以“试听音效”。
- 操作都在游戏画面里（参考《大富翁 11》）：轮到你时画面底部出现会发光的大骰子按钮和道具卡栏；买地、盖楼、选路、进店等决定以带角色头像的对话框弹出在画面底部；别人的回合只显示一个小提示。右侧栏只放玩家信息、记录和聊天。
- 速度可调（慢速 / 中速 / 快速），另有托管、认输、联机聊天；手机上也能玩。
- 联机时服务器会按动画时长安排电脑行动的节奏，保证大家看到的进度一致。

## 代码结构

```
monoplay/
├── server.js          联机服务器：静态文件 + 房间 API（POST）+ 状态推送（Server-Sent Events），电脑玩家在服务器上行动
├── public/
│   ├── engine.js      游戏引擎（纯状态机，浏览器和服务器共用；状态可序列化，随机数可复现）
│   ├── ai.js          电脑玩家策略
│   ├── app.js         前端界面：主页、房间、HUD、动画队列、音效、弹窗
│   ├── board3d.js     3D 场景（Three.js）：路网、楼房、棋子、镜头、点击拾取、物理骰子
│   ├── characters.js  6 个角色的 Q 版 3D 模型
│   ├── districts.js   四个街区的主题景观（古城、金融区、海滨、游乐园）
│   ├── buildings.js   地产楼房的四套风格造型、地块铺装和空地摆设
│   ├── suburbs.js     棋盘外的郊区：环岛路和车流、机场、港口、农田、体育场等
│   ├── sound.js       Web Audio 合成音效
│   ├── vendor/        Three.js r160、cannon-es 物理引擎（均为 MIT 许可，本地打包，无需外网）
│   ├── index.html
│   └── style.css
└── test/engine.test.js  用电脑玩家自动跑几百局，检查引擎不会卡死或进入非法状态
```

- 地图是 `engine.js` 顶部的一段字符画（`MAP`），每个字符是一个格子，相邻字符之间自动连成路；改字符画就能换地图。
- 所有规则都在 `engine.js` 的 `applyAction(state, playerId, action)` 里。想加新道具卡，在 `CARDS` 中登记，再在 `cardTargets` 和 `useCard` 里各加一个分支；机会、命运、新闻、转盘事件都是数据表，直接加条目即可。
- 联机时状态由服务器权威计算，客户端只发送行动，所以玩家没法作弊改钱；服务器下发状态前会去掉随机数种子和股票的下回合走势，内幕消息只发给打听到的人，客户端无法预测骰子和股价。

运行测试：

```bash
npm test
```
